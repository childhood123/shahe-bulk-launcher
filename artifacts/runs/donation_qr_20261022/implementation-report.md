# 打赏二维码资源接入

用户上传的两张 JPEG 原图保存于根目录“打赏”，原文件名采用既有菜单要求的“微信赞赏码.jpg”和“支付宝赞赏码.jpg”。构建与发布复制到 EXE 旁边的“打赏”文件夹。UpdateService 优先从该目录解析图片，并保留旧位置回退。

现有 QRCodeDialog 已有“复制二维码”按钮及 Clipboard.SetImage 实现，本轮复用它；真实窗体测试点击按钮，检查剪贴板图片的完整尺寸和像素，并验证中文按钮文案、读屏名称及焦点顺序。没有重绘、转码或裁剪二维码。

验证命令、RED/GREEN、全量和构建数字以 PROJECT_STRUCTURE.md 最新 DONATE-01 记录与本目录结果 JSON 为准；image-copy-verification.json 记录源目录、构建和发布副本对原始上传字节的哈希核对。

这项资源接入完成不代表整个迁移完成，AUDIT-03 剩余真实场景与后续发布验收继续保留。
