# 快捷键功能列表回车执行

用户已确认所有功能行采用同一行为。

功能列表获得焦点时，无修饰 Enter 选择当前 action，关闭快捷键窗口，随后复用主窗体现有 DispatchApplicationAction。安排到 UI 消息队列执行，避免“热键设置”自身动作造成模态嵌套或持有已关闭窗口。移动/选择不执行动作。

快捷键编辑框继续捕获 Enter；确定按钮沿用原保存行为。动作执行不保存未确认的热键编辑。原业务确认、配置键、文案、布局和焦点顺序保留，不增加依赖。

契约测试枚举生产 ActionSpecs 的所有行并截获现有分派入口，覆盖关闭后只执行一次及配置不变；真实 EXE 使用软件设置这一非破坏性代表验证完整 UI 路径。原 Python 不提供本入口，差异为用户指定增强。

执行步骤以唯一活动计划中的 HOTKEY-ENTER-01 为准。此前 AUDIT-04 未验收项不由此关闭。
